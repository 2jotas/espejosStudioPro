## 🚀 Plan de acción en 3 días para la opción 2

### Día 1 – Preparación del funnel y del CRM
1. **Seleccionar el producto Hotmart**  
   - Busca en el Marketplace de Hotmart “productos con alta comisión” y “baja tasa de reembolso”.  
   - Prioriza nichos afines a tu audiencia actual (p.ej., desarrollo personal, cursos de maquillaje/visagismo, productividad).  

2. **Crear la landing page**  
   - Usa una herramienta **drag‑and‑drop** (ClickFunnels, Leadpages o Systeme.io).  
   - Plantilla recomendada: “Lead Magnet → Video Sales Letter → Checkout”.  
   - Inserta los siguientes bloques:
     - **Headline** que conecte con el dolor del cliente.  
     - **Video corto** (60‑90 seg) que presente el producto (puedes usar el video promocional del propio creador).  
     - **Testimonios** (extrae los que aparecen en Hotmart).  
     - **CTA clara** (“Quiero acceder ahora”).  

3. **Configurar el CRM (espejosstudio.cl)**  
   - El error *“no such table: Client”* indica que la tabla de clientes está ausente.  
   - **Acción inmediata:**  
     ```sql
     CREATE TABLE Client (
         id INTEGER PRIMARY KEY AUTOINCREMENT,
         nombre TEXT NOT NULL,
         email TEXT NOT NULL UNIQUE,
         telefono TEXT,
         origen TEXT,
         fecha_registro DATETIME DEFAULT CURRENT_TIMESTAMP
     );
     ```  
   - Si no tienes acceso directo a la DB, informa al equipo de IT para que lo implementen **hoy mismo**.  
   - Integra la landing page con el CRM mediante webhook (Zapier o Integromat) para que cada lead se registre automáticamente.  

4. **Crear el lead magnet** (opcional pero potencia la tasa de conversión)  
   - Un PDF de 2‑3 páginas con “5 errores de imagen que están saboteando tu negocio”.  
   - Usa tu expertise de visagismo para darle valor y credibilidad.  

### Día 2 – Campañas de Ads automatizadas
1. **Pixel de Facebook/Meta** instalado en la landing page.  
2. **Segmentación inicial** (prueba A/B):
   - **Intereses:** “Corte de pelo masculino”, “Barba”, “Estilismo”, “Emprendedores”.
   - **Edad:** 25‑45 años, ambos géneros (si el producto es neutro) o solo hombres si es un curso de barbería.
   - **Look‑alike** del 1 % basado en tu base de clientes actuales (CRM).  

3. **Creativos** (30 seg cada uno):
   - **Video 1:** Tú explicando brevemente el beneficio del producto + CTA.  
   - **Imagen 2:** Testimonio con foto antes‑después.  
   - **Historia 3:** Mini‑tutorial (ejemplo de “cómo elegir el estilo de barba según forma facial”).  

4. **Presupuesto inicial**:  
   - **$10‑$15 USD/día** en Facebook/Instagram + **$5 USD/día** en Google Discovery.  
   - Configura **optimización para conversiones** (lead o compra).  

5. **Automatización de email** (Mailchimp o ConvertKit):
   - **Email 1 (Inmediato):** “¡Gracias por tu interés! Aquí tienes tu guía + enlace al producto”.  
   - **Email 2 (24 h):** Recordatorio + testimonio adicional.  
   - **Email 3 (48 h):** Oferta limitada (descuento 10 % si compra en 48 h).  

### Día 3 – Test, ajustes y escalado rápido
1. **Revisar métricas clave** (CTR, CPL, CPA).  
2. **Optimizar creativos**: pausa el anuncio con peor CTR y duplica el que mejor rinde.  
3. **Ajustar segmentación**: si el CPA es alto, refina intereses o usa audiencias “Engaged Users”.  
4. **Escalar**: cuando el CPA esté bajo (ej. < $5 USD), aumenta el presupuesto en 20 % diarios hasta alcanzar el ROAS deseado.
