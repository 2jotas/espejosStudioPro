## 1. Forma más rápida (línea de comandos)

```bash

```

- **\<usuario\>**: el usuario con permiso de SSH en el VPS.  
- **/ruta/al/directorio**: el directorio donde quieres ejecutar el comando.  
- **\<tu‑comando\>**: el comando que deseas correr (por ejemplo `npm run build`, `git pull`, `ls -l`, etc.).

> **⚠️ Nota de seguridad**  
> - Asegúrate de que la clave SSH o la contraseña estén protegidas y no se compartan en texto plano.

## 2. Desde un script Python (usando **paramiko**)

Si prefieres automatizar la tarea, este fragmento de código Python abre una sesión SSH, cambia al directorio indicado y ejecuta el comando:

```python
import paramiko
import sys

# -------------------------------------------------
# Configuración – REEMPLAZA con tus datos reales
# -------------------------------------------------
HOST = "100.93.160.96"
USER = "tu_usuario"
KEY_PATH = "/ruta/a/tu/id_rsa"          # o usa password si lo prefieres
# PASSWORD = "tu_password"              # <-- descomenta si usas password
TARGET_DIR = "/ruta/al/directorio"
COMMAND = "tu_comando_a_ejecutar"       # ej. "npm run build"

# -------------------------------------------------
# Conexión SSH
# -------------------------------------------------
ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())

try:
    # Si usas clave privada:
    ssh.connect(HOST, username=USER, key_filename=KEY_PATH)
    # Si usas password, usa:
    # ssh.connect(HOST, username=USER, password=PASSWORD)

    # Construimos el comando completo
    full_cmd = f'cd {TARGET_DIR} && {COMMAND}'
    stdin, stdout, stderr = ssh.exec_command(full_cmd)

    # Capturamos salida y errores
    out = stdout.read().decode()
    err = stderr.read().decode()

    if out:
        print("🟢 Salida del comando:\n", out)
    if err:
        print("🔴 Errores del comando:\n", err)

except paramiko.SSHException as e:
    print(f"🔴 Error de conexión SSH: {e}", file=sys.stderr)
finally:
    ssh.close()
```

### Qué hace el script
1. **Conecta** al VPS mediante SSH (clave privada o contraseña).  
2. **Ejecuta** `cd /ruta/al/directorio && <comando>`.  
3. **Imprime** la salida estándar (🟢) y los errores (🔴).

## 3. Alternativa con **Docker exec** (si el proceso está dentro de un contenedor)

Si el directorio que necesitas está dentro de un contenedor Docker que ya está corriendo, puedes usar:

```bash
docker exec -w /ruta/al/directorio <nombre_o_id_del_contenedor> <tu-comando>
```

- `-w` establece el *working directory* dentro del contenedor.  
- Útil para tareas como migraciones de base de datos, compilaciones, etc.
