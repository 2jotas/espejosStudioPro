## 2️⃣ DISEÑO DE LA FÁBRICA DE CONTENIDO (auto.espejosstudio)

### 2.1. **Plantilla de generación automática**
| Paso | Acción | Herramienta |
|---|---|---|
| **Input del brief** | Nombre del set (p.ej., “Alphabet A – Lion”) + idioma | Formulario web (campo “Título”, “Idioma”, “Tema”) |
| **Prompt a IA (Stable Diffusion / Midjourney)** | “Line art, black & white, printable coloring page, style similar to classic children’s books, include a large letter ‘A’, lion illustration, simple background” | API integrada en `auto.espejosstudio` |
| **Post‑process** | Vectorizar (Adobe Illustrator Script), ajustar márgenes A4/US‑Letter, añadir número de página y copyright | Node‑JS + SVGO |
| **Export** | PDF listo para venta + JPG thumbnail | Cloud storage (S3) |
| **Metadata** | Tags SEO, descripción, precio sugerido | Base de datos `products_meta` |

### 2.2. **Workflow automatizado (Zapier/Make)**
1. **Trigger** – Nuevo registro en el formulario → `auto.espejosstudio`.
2. **Action 1** – Llamada a la IA → genera PNG.
3. **Action 2** – Script de vectorización → PDF + JPG.
4. **Action 3** – Subida a **Hotmart** (producto digital) y **Etsy** (digital download) vía sus APIs.
5. **Action 4** – Creación de **Landing Page** en `auto.espejosstudio` (Plantilla “Coloring‑Launch”) con embed de botón “Comprar”.
6. **Action 5** – Envío a **Mailchimp** → lista “Colorear Fans” + secuencia de bienvenida (3 correos con muestra gratuita + upsell de bundle).

> **Resultado:** Cada nuevo concepto de imagen se publica automáticamente en ambas plataformas y en nuestras redes sociales (TikTok/IG Reels) con el video de “speed‑coloring”.
