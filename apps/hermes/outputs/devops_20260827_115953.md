3. **Comandos de verificación**  
   ```bash
   # 1️⃣ Validar compose
   docker compose config

   # 2️⃣ Construir imagen de prueba
   docker compose build --no-cache

   # 3️⃣ Health‑check local
   docker compose up -d
   curl -f http://localhost:8888/api/status && echo "OK"
   ```

4. **Rollback automático** (si `curl` falla)  
   ```bash
   docker compose down
   docker compose up -d --pull=always
   ```

## 🚀 Cómo empezar rápidamente (para un nuevo colaborador)

```bash
# 1️⃣ Clonar el repo
git clone git@github.com:2jotas/espejosStudioPro.git
cd espejosStudioPro/estadistica/semana-4

# 2️⃣ Levantar el entorno (requiere Docker + Docker‑Compose)
docker compose up -d

# 3️⃣ Acceder a Jupyter (el token está en el log)
docker logs estadistica_sem4_jupyter | grep token
# Abrir en navegador: https://<gateway‑host>/jupyter
```

> **⚠️** No olvides que el gateway solo permite los puertos `80` y `443`. Si deseas exponer otro puerto, deberás hacerlo **únicamente** detrás de un proxy reverso gestionado por `espejos-gateway`.
