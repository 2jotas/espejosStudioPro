## 🛠️ Tips de organización y automatización

1. **Nombrado consistente**  
   - Usa `YYYYMMDD_Descripción.ext` para archivos que evolucionan (ej. `20240415_Examen_Calculo1.pdf`).  
   - Evita espacios; usa guiones bajos o guiones medios.

2. **Control de versiones**  
   - Inicializa un **repo Git** en la raíz (`git init`).  
   - Añade un `.gitignore` que excluya datos pesados (`*.csv`, `*.parquet`) y carpetas de entornos (`env/`, `__pycache__/`).  
   - Commits frecuentes con mensajes claros (`git commit -m "Add notebook on regresión lineal"`).

3. **Entorno reproducible**  
   - Crea un archivo `environment.yml` (Conda) o `requirements.txt` con todas las dependencias del curso.  
   - Ejemplo `environment.yml`:

   ```yaml
   name: ing-ciencia-datos
   channels:
     - conda-forge
   dependencies:
     - python=3.11
     - numpy
     - pandas
     - scipy
     - scikit-learn
     - matplotlib
     - seaborn
     - jupyterlab
     - sqlalchemy
     - pyspark
   ```

   Luego, en cualquier máquina: `conda env create -f environment.yml`.

4. **Plantillas de notebooks**  
   - Guarda una plantilla base en `Herramientas‑y‑Scripts/Plantillas-Jupyter/` con secciones predefinidas: *Objetivo*, *Importaciones*, *Carga de datos*, *EDA*, *Modelo*, *Conclusiones*.  
   - Copia y renombra cada vez que empieces un nuevo proyecto.

5. **Documentación rápida**  
   - Usa un `README.md` en cada carpeta principal (ej. `01‑Primer‑Año/README.md`) donde describas brevemente el contenido, los objetivos del semestre y los enlaces a recursos externos.  
   - Ejemplo:

   ```markdown
   # 01‑Cálculo
   ## Contenido
   - Apuntes de clase (PDF)
   - Ejercicios resueltos
   - Exámenes parciales

   ## Recursos recomendados
   - *Thomas' Calculus* – Cap. 1‑4
   - Khan Academy: [Cálculo diferencial](https://es.khanacademy.org/math/calculus-1)
   ```

6. **Backups automáticos**  
   - Configura OneDrive (ya lo usas) o Google Drive para sincronizar la carpeta completa.  
   - Opcional: usa `rsync` o `robocopy` para crear copias locales cada fin de semana.

## 🚀 Primeros pasos para ti

1. **Crear la estructura**  
   Abre PowerShell (o CMD) y ejecuta:

   ```powershell
   cd "C:\Users\dyna\OneDrive\Escritorio"
   mkdir ing-ciencia-datos
   cd ing-ciencia-datos

   # Años
   1..4 | ForEach-Object { New-Item -ItemType Directory -Name "$("{0:D2}" -f $_)-Año" }

   # Dentro del primer año, crear subcarpetas de ejemplo
   cd "01-Año"
   @("Cálculo","Álgebra-Lineal","Programación-Python","Introducción-a-Estadística") |
       ForEach-Object { New-Item -ItemType Directory -Name $_ }
   ```

2. **Inicializar Git**  

   ```bash
   cd "C:\Users\dyna\OneDrive\Escritorio\ing-ciencia-datos"
   git init
   echo "env/\n__pycache__/\n*.csv\n*.parquet" > .gitignore
   git add .
   git commit -m "Estructura inicial del vault de estudio"
   ```

3. **Crear el entorno Conda**  

   ```bash
   conda env create -f environment.yml   # (crea el archivo antes)
   conda activate ing-ciencia-datos
   ```

4. **Añadir la primera plantilla de notebook**  

   ```markdown
   # Herramientas-y-Scripts/Plantillas-Jupyter/template.ipynb
   ```

   (Puedes crearla manualmente en JupyterLab y guardarla como plantilla).
