## 2️⃣ Solución al error de Docker

El mensaje `Error querying docker: [Errno 2] No such file or directory: 'docker'` indica que el binario **docker** no está presente.  

### Paso 1 – Instalar Docker (Ubuntu/Debian)

```bash
# Actualizar repositorios
sudo apt-get update

# Instalar paquetes requeridos
sudo apt-get install -y \
    ca-certificates \
    curl \
    gnupg \
    lsb-release

# Añadir la GPG key oficial de Docker
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# Configurar el repositorio
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Instalar Docker Engine
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io

# Verificar instalación
docker --version
```

### Paso 2 – Añadir el usuario al grupo `docker` (para evitar `sudo`)

```bash
sudo usermod -aG docker $USER
newgrp docker   # o cerrar sesión y volver a entrar
```

### Paso 3 – Confirmar que Docker funciona

```bash
docker run --rm hello-world
```

Deberías ver el mensaje *“Hello from Docker!”* → Docker está operativo.

## 4️⃣ Monitoreo y salud de los servicios (emojis)

| Servicio | Puerto | Estado esperado | Emoji |
|----------|--------|----------------|-------|
| Nginx Gateway | 8080 / 8443 | Responde 200 a `/healthz` | 🟢 |
| API Fastify | 3000 | Responde 200 a `/ping` | 🟢 |
| Web React | 3001 | Sirve `index.html` | 🟢 |
| Postgres | 5432 | `pg_isready` → `accepting connections` | 🟢 |
| Redis | 6379 | `redis-cli ping` → `PONG` | 🟢 |

> **Comando rápido de chequeo** (ejecutar en la VPS)

```bash
#!/usr/bin/env bash
services=(
  "nginx:curl -s -o /dev/null -w \"%{http_code}\" http://localhost:8080/healthz"
  "fastify:curl -s -o /dev/null -w \"%{http_code}\" http://localhost:3000/ping"
  "react:curl -s -o /dev/null -w \"%{http_code}\" http://localhost:3001"
  "postgres:pg_isready -h localhost -p 5432"
  "redis:redis-cli -h localhost ping"
)

for s in "${services[@]}"; do
  name=${s%%:*}
  cmd=${s#*:}
  if output=$(eval "$cmd" 2>/dev/null); then
    case "$name" in
      nginx|fastify|react) [[ $output == 200 ]] && echo "$name 🟢" || echo "$name 🔴 (code $output)";;
      postgres) [[ $output == *accepting* ]] && echo "$name 🟢" || echo "$name 🔴 ($output)";;
      redis) [[ $output == PONG ]] && echo "$name 🟢" || echo "$name 🔴 ($output)";;
    esac
  else
    echo "$name 🔴 (no response)"
  fi
done
```

## 5️⃣ Flujo de despliegue con aprobación por Telegram

1. **CI** (GitHub Actions) ejecuta lint, tests y *docker‑build* → genera una imagen etiquetada `registry.example.com/formacion-ciencia-datos:<sha>`.  
2. **Bot de Telegram** (ya configurado) envía mensaje:

   ```
   🚀 *Despliegue pendiente*  
   Repo: 2jotas/formacion-ciencia-datos  
   Commit: <sha>  
   Imagen: registry.example.com/formacion-ciencia-datos:<sha>  
   ✅ Aprobar | ❌ Rechazar
   ```

3. Al pulsar **✅ Aprobar**, el bot dispara un webhook que ejecuta:

   ```bash
   docker compose pull   # trae la nueva imagen
   docker compose up -d  # reinicia los contenedores
   ```

4. Bot responde con el estado final (🟢 OK o 🔴 Error) y registra la acción en un canal de auditoría.

## 6️⃣ Recomendaciones de seguridad y buenas prácticas

| Área | Acción recomendada |
|------|-------------------|
| **Variables de entorno** | Mantener `.env` fuera del repositorio; usar GitHub Secrets y montar como `docker secret` o `env_file` con permisos `600`. |
| **Imágenes** | Pin a versiones específicas; escanear con `trivy` o `snyk` en CI. |
| **Redes** | Aislar contenedores críticos (Postgres, Redis) en una red Docker interna; exponer solo Nginx al exterior. |
| **Actualizaciones** | Programar `apt-get upgrade` y `docker system prune -a` semanalmente. |
| **Backups** | Dump de Postgres y snapshot de volúmenes Redis → almacenar en S3 o OneDrive con cifrado. |
| **Logs** | Enviar logs de Nginx y Fastify a un stack ELK o Loki para detección de anomalías. |
| **Tailscale** | Mantener la red privada (`100.93.160.96`) como única vía de acceso SSH y Docker. |
