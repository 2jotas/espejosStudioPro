### 📋 Resumen del problema
El cliente recibe el error:

```
Error accediendo al socket de Docker: [Errno 2] No such file or directory: 'docker'
```

Esto indica que la CLI `docker` no puede encontrar el socket Unix (`/var/run/docker.sock`) o la propia binaria no está en el `$PATH`. Las causas más habituales son:

| Posible causa | Síntomas típicos |
|---------------|-------------------|
| Docker **no está instalado** | `which docker` devuelve nada; `docker --version` falla. |
| Servicio Docker **detenido** o **no iniciado** | `systemctl status docker` → *inactive* / *failed*. |
| **Permisos** insuficientes para acceder a `/var/run/docker.sock` | El socket existe pero `ls -l` muestra `root:root` sin el grupo `docker`. |
| **Docker socket en ubicación no estándar** (p.ej. `DOCKER_HOST` apunta a otra ruta) | Variable de entorno `DOCKER_HOST` mal configurada. |
| Entorno **no es el VPS** (por ejemplo, una sesión de SSH a otro host) | No hay `/var/run/docker.sock` porque el host no es el nodo Docker. |
