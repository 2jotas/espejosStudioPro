## 🎯 Objetivo  
Crear la **estructura inicial** de la web **formacion.espejosstudio.cl** que sirva como portal de formación en Ciencia de Datos.  
El proyecto debe estar **conectado al repositorio GitHub `formacion-ciencia-datos`** y listo para escalar (añadir cursos, blogs, autenticación, etc.).

---

## 1️⃣ Elección tecnológica

| Necesidad | Opción recomendada | Por qué |
|-----------|-------------------|--------|
| **Renderizado rápido + SEO** | **Next.js 14 (React)** | SSR/SSG out‑of‑the‑box, rutas dinámicas y API Routes. |
| **Gestión de contenido** | **MDX + Contentlayer** | Permite escribir lecciones como archivos Markdown/MDX y generar páginas estáticas. |
| **Estilos** | **Tailwind CSS** | Utility‑first, muy rápido para prototipos y fácil de mantener. |
| **Autenticación (futuro)** | **NextAuth.js** + **Google / GitHub** | Integración simple con API Routes. |
| **Deploy** | **Vercel** (con GitHub Actions) | Deploy instantáneo y preview‑deploy por rama. |
| **Base de datos (opcional)** | **Supabase** (PostgreSQL + Auth) | Si más adelante necesitas guardar progreso, quizzes, etc. |
| **CI/CD** | **GitHub Actions** | Lint, tests, build y preview en Vercel. |

> **Tip:** Si prefieres un stack “sin servidor”, puedes usar **Astro** + **Netlify**. La estructura propuesta sigue siendo válida; solo cambia el `framework` y los scripts de build.

### Detalle de carpetas clave

| Carpeta | Propósito |
|--------|-----------|
| **src/app/** | Rutas de la aplicación (App Router). Cada carpeta entre paréntesis `()` es un **route group** que permite compartir layout o middleware. |
| **src/components/** | Componentes UI reutilizables (Header, Footer, Card, etc.). |
| **src/lib/** | Lógica de negocio: conexión a Supabase, fetch de contenido, helpers. |
| **src/mdx/** | Fuente del contenido. Cada `.mdx` contiene front‑matter (`title`, `description`, `tags`, `duration`, `level`). |
| **public/** | Imágenes de marca, logos, favicon, videos de presentación, etc. |
| **.github/workflows/ci.yml** | CI: lint → test → build → preview (Vercel). |

## 4️⃣ Configuración esencial

### `next.config.mjs`

```js
import { createContentlayerPlugin } from 'next-contentlayer';

const withContentlayer = createContentlayerPlugin();

export default withContentlayer({
  reactStrictMode: true,
  // Redirección de dominio
  async redirects() {
    return [
      {
        source: '/',
        destination: '/home',
        permanent: true,
      },
    ];
  },
});
```

```ts
import type { Config } from 'tailwindcss';

export default {
```
