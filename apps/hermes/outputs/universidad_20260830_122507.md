## Modelos descriptivos vs. modelos predictivos  
*(como lo explicaría un profesor de Ingeniería en Ciencia de Datos)*  

---

### 1. ¿Qué es un **modelo descriptivo**?

| Característica | Detalle |
|----------------|---------|
| **Objetivo** | **Entender** y **resumir** lo que ya ocurrió. No se busca predecir el futuro, sino extraer patrones, relaciones y estructuras de los datos históricos. |
| **Tipo de salida** | Estadísticas, visualizaciones, agrupaciones, reglas de asociación, etc. |
| **Preguntas típicas** | • ¿Cuál es la distribución de la variable X?<br>• ¿Qué variables están correlacionadas?<br>• ¿Qué segmentos de clientes existen?<br>• ¿Qué tendencias se observan en los últimos 12 meses? |
| **Métodos comunes** | • Estadísticas descriptivas (media, mediana, moda, varianza, percentiles).<br>• Visualizaciones (histogramas, box‑plots, heatmaps, pair‑plots).<br>• Análisis de correlación y covarianza.<br>• Análisis de componentes principales (PCA).<br>• Clustering (K‑means, DBSCAN, jerárquico).<br>• Reglas de asociación (Apriori, FP‑Growth). |
| **Ventajas** | • Fácil de interpretar.<br>• No requiere suposiciones fuertes sobre la generación de datos.<br>• Sirve como paso preliminar para cualquier proyecto de datos. |
| **Limitaciones** | • No permite anticipar eventos futuros.<br>• Puede ser engañoso si se ignoran efectos de confusión o variables ocultas. |

#### Ejemplo práctico (Python / Pandas)

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Supongamos que tenemos un DataFrame llamado df
df = pd.read_csv('ventas.csv')

# 1️⃣ Estadísticas descriptivas básicas
print(df.describe())

# 2️⃣ Correlación entre variables numéricas
corr = df.corr()
sns.heatmap(corr, annot=True, cmap='coolwarm')
plt.title('Matriz de correlación')
plt.show()

# 3️⃣ Agrupación (clustering) con K‑means
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

X = df[['Precio', 'Cantidad']].dropna()
X_scaled = StandardScaler().fit_transform(X)

kmeans = KMeans(n_clusters=3, random_state=42)
df['Cluster'] = kmeans.fit_predict(X_scaled)

sns.scatterplot(data=df, x='Precio', y='Cantidad', hue='Cluster', palette='Set2')
plt.title('Clustering de productos')
plt.show()
```

### 2. ¿Qué es un **modelo predictivo**?

| Característica | Detalle |
|----------------|---------|
| **Objetivo** | **Predecir** valores o clases de datos que aún no se han observado, usando patrones aprendidos de datos históricos. |
| **Tipo de salida** | Variable continua (regresión) o variable categórica (clasificación). |
| **Preguntas típicas** | • ¿Cuál será la demanda del próximo mes?<br>• ¿Qué cliente tiene mayor probabilidad de churn?<br>• ¿Cuál será el precio óptimo para maximizar ingresos?<br>• ¿Qué riesgo de fraude tiene una transacción? |
| **Métodos comunes** | • Regresión lineal, Ridge, Lasso.<br>• Árboles de decisión, Random Forest, Gradient Boosting (XGBoost, LightGBM, CatBoost).<br>• Redes neuronales (MLP, CNN, RNN, Transformers).<br>• Máquinas de soporte vectorial (SVM).<br>• Modelos de series temporales (ARIMA, Prophet, LSTM). |
| **Pipeline típico** | 1️⃣ **Recolección y limpieza** → 2️⃣ **Ingeniería de características** → 3️⃣ **División train‑test/validación** → 4️⃣ **Entrenamiento** → 5️⃣ **Evaluación** (MSE, MAE, R², Accuracy, ROC‑AUC, etc.) → 6️⃣ **Ajuste de hiperparámetros** → 7️⃣ **Despliegue**. |
| **Ventajas** | • Permite tomar decisiones proactivas (optimizar precios, planificar inventario, detectar fraudes).<br>• Puede automatizar procesos de negocio. |
| **Limitaciones** | • Depende de la calidad y representatividad de los datos de entrenamiento.<br>• Riesgo de sobre‑ajuste (overfitting) y sesgo (bias).<br>• Necesita monitoreo continuo cuando el entorno cambia (concept drift). |

#### Ejemplo práctico (Regresión lineal con scikit‑learn)

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score
import matplotlib.pyplot as plt

# Simulamos un dataset de ventas
np.random.seed(0)
n = 200
X = np.random.rand(n, 1) * 10          # Precio del producto (0‑10)
y = 50 + 5 * X + np.random.randn(n, 1) * 3   # Ventas = 50 + 5*Precio + ruido

df = pd.DataFrame(np.hstack([X, y]), columns=['Precio', 'Ventas'])

# 1️⃣ División train / test
X_train, X_test, y_train, y_test = train_test_split(
    df[['Precio']], df['Ventas'], test_size=0.2, random_state=42)

# 2️⃣ Entrenamiento
modelo = LinearRegression()
modelo.fit(X_train, y_train)

# 3️⃣ Predicción y evaluación
y_pred = modelo.predict(X_test)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print(f"MAE  : {mae:.2f}")
print(f"R²   : {r2:.3f}")

# 4️⃣ Visualización
plt.scatter(X_test, y_test, color='steelblue', label='Datos reales')
plt.plot(X_test, y_pred, color='orange', linewidth=2, label='Predicción')
plt.xlabel('Precio')
plt.ylabel('Ventas')
plt.title('Regresión lineal: Precio vs. Ventas')
plt.legend()
plt.show()
```

### 3. Comparación rápida

| Aspecto | Modelo descriptivo | Modelo predictivo |
|---------|-------------------|-------------------|
| **Propósito** | Resumir y explicar el pasado. | Anticipar el futuro. |
| **Salida** | Estadísticas, clusters, reglas. | Valores continuos o etiquetas. |
| **Métodos típicos** | Estadística básica, visualización, clustering, PCA, asociación. | Regresión, clasificación, series temporales, deep learning. |
| **Evaluación** | No hay “error” de predicción; se usan métricas de ajuste (R², varianza explicada) o calidad de agrupación (silhouette). | Métricas de error (MSE, MAE) o de clasificación (accuracy, F1, ROC‑AUC). |
| **Uso en negocio** | Informes de desempeño, segmentación de clientes, detección de outliers. | Forecast de demanda, scoring de crédito, detección de fraude en tiempo real. |
| **Dependencia de datos** | Menos sensible a cambios drásticos; sirve como diagnóstico. | Muy sensible a cambios en la distribución (concept drift). |

### 4. Cómo integrarlos en un **pipeline de proyecto de Ciencia de Datos**  

1. **Exploración y análisis descriptivo**  
   - Genera **reportes automáticos** (p.ej., con `pandas_profiling` o `sweetviz`).  
   - Identifica variables relevantes, valores faltantes, outliers y relaciones lineales/no lineales.  

2. **Ingeniería de características** (basada en insights descriptivos)  
   - Creación de variables derivadas (log, interacciones, bins).  
   - Codificación de variables categóricas (One‑Hot, Target Encoding).  

3. **Modelado predictivo**  
   - Selección de algoritmo(s) según el tipo de problema y la naturaleza de los datos.  
   - Validación cruzada y búsqueda de hiperparámetros (`GridSearchCV`, `Optuna`).  

4. **Interpretabilidad** (puente entre descriptivo y predictivo)  
   - **SHAP** o **LIME** para explicar la contribución de cada característica a la predicción.  
   - Permite volver al nivel descriptivo y comunicar resultados a stakeholders no técnicos.  

5. **Despliegue y monitoreo**  
   - Convertir el modelo en una API (FastAPI, Flask) o en un batch job.  
   - Monitorear métricas de desempeño y **drift** de datos; si el drift supera un umbral, volver a la fase descriptiva para re‑analizar.  

---

### 5. Buenas prácticas y “gotchas”

| Área | Recomendación |
|------|---------------|
| **Datos** | Siempre verifica la **calidad** (missing, duplicados, outliers). Un modelo predictivo con datos sucios heredará esos errores. |
| **Feature Engineering** | Usa la información obtenida en el análisis descriptivo (p.ej., variables altamente correlacionadas pueden combinarse o eliminarse). |
| **Overfitting** | Aplica regularización (Ridge/Lasso) o técnicas de bagging/boosting. Usa validación cruzada. |
| **Interpretabilidad** | En entornos regulados (finanzas, salud) prefiere modelos más interpretables (regresión logística, árboles). |
| **Reproducibilidad** | Fija semillas aleatorias (`random_state`), guarda versiones de datos y código (Git, DVC). |
| **Comunicación** | Complementa los resultados predictivos con visualizaciones descriptivas que muestren *por qué* el modelo tomó cierta decisión. |

---

## 6. Resumen final

- **Modelos descriptivos** = **“qué pasó”**. Sirven para **explorar**, **entender** y **comunicar** la información existente. Son la base sobre la que se construye cualquier proyecto de ciencia de datos.  
- **Modelos predictivos** = **“qué pasará”**. Utilizan los patrones descubiertos (a menudo gracias al análisis descriptivo) para **predecir** y **optimizar** decisiones futuras.  

Dominar ambos tipos de modelos y saber cuándo y cómo combinarlos es esencial para un ingeniero de ciencia de datos competente.
