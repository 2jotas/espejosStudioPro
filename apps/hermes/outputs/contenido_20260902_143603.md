## 1️⃣ Visión General del Sistema “Auto‑Content Engine”

| **Módulo** | **Objetivo** | **Tecnología Sugerida** | **Dónde se aloja** |
|------------|--------------|--------------------------|---------------------|
| **1️⃣ Trend Miner** | Captura de tendencias en tiempo real (TikTok, Reels, Shorts, X) | Python + **TikTok Scraper API**, **Instagram Graph API**, **YouTube Data API**, **Twitter API v2** + **Google Trends** | **AWS Lambda** (ejecución cada 30 min) |
| **2️⃣ Idea Generator** | Transforma la tendencia en “hook” + ángulo de valor | **OpenAI GPT‑4o** (prompt dinámico) | **OpenAI Cloud** (llamadas HTTP) |
| **3️⃣ Script & Copy Builder** | Genera guión estructurado (Hook, Retención, Valor, CTA) + copys para carrusel y títulos | **OpenAI GPT‑4o**, plantillas Jinja2 | **AWS Lambda** (función separada) |
| **4️⃣ Media Factory** | Crea vídeo corto (texto‑a‑voz, stock, subtítulos, branding) | **Pictory / Veed.io API**, **ElevenLabs TTS**, **FFmpeg** | **Render Farm en Render.com** (auto‑escalable) |
| **5️⃣ Asset Store** | Guarda vídeos, imágenes, copys, JSON de metadatos | **AWS S3** (bucket `auto-content-assets`) + **CloudFront CDN** | AWS |
| **6️⃣ Funnel Builder** | Genera landing page / lead‑magnet y secuencia de email | **Webflow API** (páginas) + **MailerLite / ConvertKit API** (emails) | Webflow + MailerLite (cloud) |
| **7️⃣ Scheduler & Publisher** | Publica automáticamente en cada red | **Zapier / Make (Integromat)** + **API nativas** (TikTok, Instagram, YouTube Shorts, X) | Zapier (plan Business) |
| **8️⃣ Analytics Hub** | Recolecta métricas en tiempo real y dispara alertas | **Google Data Studio**, **Metriql**, **Supabase** para DB en tiempo real | Supabase + Data Studio |
| **9️⃣ UI Control Panel** | Dashboard donde ajustas parámetros, revisas colas y métricas | **Streamlit** (Python) o **Retool** (no‑code) conectado a Supabase | Deploy en **Vercel** bajo sub‑dominio `auto.espejosstudio.cl` |

## 2️⃣ Flujo de Trabajo End‑to‑End (E2E)

```
[Trend Miner] → (JSON Trend Feed) → [Idea Generator] → [Script Builder] 
      → [Media Factory] → [Asset Store] → [Scheduler & Publisher] 
      → [Analytics Hub] → (feedback loop) → [Idea Generator]
```

### Paso a Paso (para el **primer run**)

| # | Acción | Herramienta | Detalle Técnico |
|---|--------|-------------|-----------------|
| 1 | **Ingesta de Tendencias** | `trend_miner.py` (AWS Lambda) | - Cron cada 30 min <br> - Query a TikTok Trending Hashtags, IG Reels Top 10, YouTube Shorts “Rising”, X “Top Tweets”. <br> - Normaliza a JSON: `{topic, platform, score, url}` |
| 2 | **Filtrado y Scoring** | Lambda + Supabase DB | - Algoritmo de puntuación: **ViralityScore = (views * 0.6) + (shares * 0.3) + (growthRate * 0.1)** <br> - Guarda los top‑5 en tabla `trends` |
| 3 | **Generación de Hook** | OpenAI `gpt‑4o` (prompt “Crea 3 hooks de 3 s para …”) | - Se envía el `topic` + `audience persona` (Barbería, IA, Finanzas…) <br> - Resultado: array de hooks. |
| 4 | **Construcción del Guión** | GPT + Jinja2 Template | ```text \n[HOOK 0‑3s] {{hook}}\n[RETENCIÓN 3‑20s] {{story}}\n[VALOR] {{tips}}\n[CTA] {{cta}}\n``` |
| 5 | **Creación de Video** | **Pictory API** (texto‑a‑video) + **ElevenLabs** (voz) | - Subimos script → Pictory genera clip con stock + branding <br> - Añadimos voz TTS y subtítulos con FFmpeg. |
| 6 | **Almacenamiento** | S3 bucket `auto-content-assets` | - `videos/{date}/{slug}.mp4` <br> - `metadata/{slug}.json` |
| 7 | **Programación de Publicación** | Zapier “Schedule” + API de cada red | - Cada video tiene `publish_at` (horario pico según audiencia). <br> - Zapier envía POST a TikTok/IG/YouTube/X con token OAuth. |
| 8 | **Landing + Lead Magnet** | Webflow + ConvertKit | - Si el CTA es “Descarga mi guía de visagismo”, Webflow crea página instantánea con formulario → ConvertKit captura lead → envía ebook (S3). |
| 9 | **Métricas en Tiempo Real** | Supabase `metrics` table + Metriql + Data Studio | - Cada API devuelve `views, likes, comments, ctr, spend`. <br> - Ingresamos a Supabase vía webhook y actualizamos dashboards. |
|10| **Feedback Loop** | Scheduler Lambda | - Si `CTR > 4%` y `CPL < $2`, marcamos el tema como “high‑ROI” y lo priorizamos en el siguiente ciclo. |

## 3️⃣ UI Control Panel (auto.espejosstudio.cl)

### Tecnologías
- **Front‑end:** Streamlit (Python) → despliegue rápido en Vercel (serverless)  
- **Back‑end:** Supabase (PostgreSQL + Realtime) para almacenar configuraciones, colas y métricas.  
- **Auth:** **Supabase Auth** (email + Google OAuth) → usuarios con rol “Admin” / “Editor”.

### Pantallas Clave

| Pantalla | Funcionalidad |
|----------|---------------|
| **Dashboard** | Gráfica de *Virality Score* por tema, KPIs (Views, Likes, CPL, Revenue). |
| **Trend Feed** | Tabla filtrable de tendencias actuales; botón **“▶️ Generar contenido”**. |
| **Script Builder** | Editor de texto con pre‑llenado automático del guión; opción *Regenerate* y *Save as Template*. |
| **Media Preview** | Player embebido (S3 URL) + botón **“Publicar ahora”** o **“Schedule”** (date‑time picker). |
| **Funnel Settings** | Selección de Lead Magnet, URL de landing, email sequence (dropdown de plantillas). |
| **Automation Settings** | Configuración global: <br> • Intervalo de scraping (30 min / 1 h) <br> • Horarios pico por plataforma <br> • Umbral de virality para auto‑publicar. |
| **Logs & Alerts** | Feed de eventos (API calls, errores, success) + notificaciones vía Slack/Discord. |
