**Bucket S3‑compatible**  

Un *bucket* S3‑compatible es un contenedor de almacenamiento de objetos que implementa la misma API y modelo de operación que Amazon S3 (Simple Storage Service). Gracias a esa compatibilidad, cualquier herramienta, SDK o aplicación diseñada para trabajar con S3 puede usar el bucket sin cambios de código.

### Qué funcionalidades ofrece
| Operación | Descripción (compatible con S3) |
|-----------|---------------------------------|
| **Crear / eliminar / listar buckets** | Gestión de contenedores de objetos. |
| **Subir / descargar / eliminar objetos** | Operaciones CRUD sobre archivos (PUT, GET, DELETE, etc.). |
| **Control de acceso** | Políticas de bucket, ACLs, firmas temporales (presigned URLs). |
| **Versionado, replicación, ciclo de vida** | Opciones avanzadas idénticas a S3 (si el proveedor las implementa). |
| **Eventos y notificaciones** | Triggers a Lambda‑like, colas, webhooks, etc. |

### Por qué es útil
- **Portabilidad**: Puedes mover cargas de trabajo entre proveedores (AWS, Google Cloud, Azure, MinIO, Ceph, etc.) sin re‑escribir código.
- **Coste y control**: Usar una solución on‑premise o de un proveedor más barato manteniendo la misma interfaz.
- **Ecosistema**: Herramientas de backup, CI/CD, CDNs, y librerías de cliente S3 funcionan directamente.

### Ejemplos de implementaciones S3‑compatible
- **MinIO** (almacenamiento de objetos de código abierto).  
- **Ceph Object Gateway**.  
- **Google Cloud Storage** (modo interoperable).  
- **Microsoft Azure Blob Storage** (con “Azure Blob Storage S3 API”).  
- **IBM Cloud Object Storage**, **DigitalOcean Spaces**, etc.

### En el contexto DevOps
- **Backups**: Automatizar copias de bases de datos o artefactos en un bucket S3‑compatible.  
- **Distribución de assets**: Servir archivos estáticos (imágenes, JS, CSS) a través de un CDN que consume S3.  
- **CI/CD**: Almacenar artefactos de compilación y despliegues.  
- **Seguridad**: Aplicar políticas de cifrado en reposo, control de acceso basado en IAM o ACLs, y auditoría de accesos.

En resumen, un bucket S3‑compatible es un punto de almacenamiento de objetos que sigue la especificación de la API de Amazon S3, permitiendo reutilizar todo el ecosistema de herramientas y código que ya funciona con S3, pero con la flexibilidad de elegir el proveedor o la infraestructura que mejor se ajuste a tus necesidades.
