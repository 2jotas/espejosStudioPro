A continuación tienes una **propuesta de UI “drag‑&‑drop”** que puedes montar en minutos usando el constructor visual de *Espejos Studio* (similar a Webflow/Retool). Cada bloque es **click‑ready** y **configurable** sin escribir código.

## 3️⃣  Flujo de trabajo paso‑a‑paso (con clicks)

1. **Crear proyecto** → Click **🔧 “Nuevo proyecto”** → rellenar formulario → **“Crear”**.  
2. **Cargar datos de mercado** → El módulo **Resumen de mercado** se actualiza vía API (CoinGecko / Binance). No hay intervención manual.  
3. **Diseñar estrategia** → En **Builder** arrastras “RSI > 65” → “Precio < EMA‑20” → “Orden‑Block Sell” → “Short”. Conecta a **Gestión de Riesgo** → se calculan automáticamente SL/TP y posición.  
4. **Validar riesgo** → El panel muestra **RR = 1.9**, **Kelly = 12 %**, **Máx DD esperado = 4 %**. Si RR < 1.5, el botón **“Publicar”** queda gris.  
5. **Backtest** → Click **“Run”** → 3 s y aparecen métricas. Si **Sharpe > 1.2** y **Max DD < 15 %**, el proyecto avanza al paso de **Aprobación**.  
6. **Aprobación** → En **Estado del flujo** aparece “Pendiente de revisión”. El líder de equipo da click **“Aprobar”** (requiere 2 firmas).  
7. **Lanzar campaña** → Click **“Publicar”** → Se genera URL pública y se activa el **Calendario de Marketing** (automático según plantilla).  
8. **Monitoreo** → En **Home Dashboard** ves KPI en tiempo real (PnL, % de objetivo alcanzado, alertas).  
9. **Iterar** → Si el precio rompe el SL, el bot cierra y el panel muestra **“Trade cerrado – Resultado: -2.3 %”** → Se actualizan estadísticas y se propone la siguiente señal.
